[#_oci_artifacts]
== OCI artifacts

The {admc-name} Helm chart and container images are Open Container Initiative
(OCI) artifacts distributed through the https://apps.rancher.io[SUSE
Application Collection]. Accessing them requires
https://docs.apps.rancher.io/get-started/authentication/[Application Collection
credentials].

- `oci://dp.apps.rancher.io/charts/suse-security-admission-controller` is the
  Helm chart.
- `dp.apps.rancher.io/containers/kubewarden-controller`,
  `dp.apps.rancher.io/containers/kubewarden-policy-server`,
  `dp.apps.rancher.io/containers/kubewarden-audit-scanner` and
  `dp.apps.rancher.io/containers/kubectl` are the container images.

The policies maintained by the {admc-short-name} team are policy Wasm OCI
artifacts published in `ghcr.io` under
https://github.com/orgs/kubewarden/packages/policies[`kubewarden/packages/policies/*`].

[#_helm_charts_via_https]
== Helm charts via HTTPS

The SUSE Application Collection distributes the {admc-short-name} Helm chart
only as an OCI artifact. There's no Helm chart HTTPS repository.
